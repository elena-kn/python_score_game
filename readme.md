📖 About the Project

Game Review Saver is a beginner-friendly Python project that allows users to save reviews for their favorite games.

With this program, you can:

- 🎮 Enter a game name
- ⭐ Give the game a rating from 1 to 5
- 📝 Write a review
- 💾 Save the review in a text file

This project was created to practice basic Python programming and file handling.

🛠️ Built With

- 🐍 Python
- 📄 Text files

🚀 How to Run

First, make sure Python is installed on your computer.

Clone the repository:

git clone YOUR-REPOSITORY-LINK

Go to the project folder:

cd Game-Review-Saver

Run the program:

python main.py

🎯 How It Works

The program asks the user for:

Game name: Minecraft
Rating (1-5): 5
Review: I really enjoyed this game!

The review is then saved in:

game_reviews.txt
